# 資產處理

程式化產生 Game3 的全部 Q 版遊戲貼圖：地形圖集、敵人、道具、旗竿、
移動平台與背景。主角紅牛沿用 Game1／Game2 的去背 PNG，不在本腳本重建範圍。

## 重建環境

`tools/.venv/` 不進版控，換一台機器要重建：

    python3 -m venv tools/.venv
    tools/.venv/bin/pip install Pillow

## 執行

    tools/.venv/bin/python tools/prepare_assets.py

輸出到 `assets/` 與 `assets/enemies/`。腳本可重複執行，相同輸入永遠得到
相同輸出——背景的 K 線高低用等差序列的三角函數產生，不用隨機數，就是為了
這一點。

## 為什麼用程式畫而不是 AI 生圖

主角紅牛是圓潤造型加粗黑輪廓的卡通風。Game2 那批熊市敵人是寫實暗黑風，
在塔防裡是遠景小圖還撐得過去，但平台遊戲玩家會貼著敵人踩，風格衝突會被
放大。程式畫能把輪廓粗細、飽和度、圓角半徑都變成腳本頂端的常數，整批素材
自然統一在同一個調性上。

## 兩個踩過的坑

**`Image.paste` 帶遮罩是取代不是疊加。** 高光與陰影畫在獨立圖層再用橢圓
遮罩裁切時，如果用 `paste`，半透明的白會把身體底色整片換成半透明白——
第一版的棕熊因此變成了熊貓。要先把遮罩用 `ImageChops.multiply` 併進圖層的
alpha 通道，再用 `alpha_composite`。

**粗輪廓撐不住太小的形狀。** Boss 的皇冠第一版寫成一條高度只有八格的鋸齒
多邊形，套上和其他素材同樣粗的輪廓，縮圖後整頂變成一團黑。粗輪廓的風格是
對的，但形狀得留得夠大——最後改成三個尖角加一條冠帶分開畫。

## 地形圖集的欄位順序

`assets/tiles.png` 是 7 格橫向圖集，每格 64×64，順序必須和
`scripts/tile_glossary.gd` 的 `atlas_column()` 一致：

| 欄 | 內容 |
|---|---|
| 0 | 地面（土塊加草皮） |
| 1 | 磚台 |
| 2 | 問號磚 |
| 3 | 頂過的磚 |
| 4 | 可破磚 |
| 5 | 地刺 |
| 6 | 水管口 |

牛奶磚刻意和問號磚共用第 2 欄——玩家要頂了才知道裡面是什麼。
